# 🛒 React Ecommerce

A practice project built to understand how React works — components, routing, hooks, and data fetching.

> ⚠️ This is **not** a fully production-ready app. It is built for learning purposes by following the [SuperSimpleDev](https://www.youtube.com/@SuperSimpleDev) YouTube tutorial and then making custom changes independently.

---

## 📌 About

- Built to learn how React components work in a real ecommerce context
- Base code is from a tutorial — I added my own components, routes, and logic on top
- Goal is to understand how state, events, routing, and fetching connect together
- Used as a personal sandbox to practice freely

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React | UI component library |
| React Router | Client-side routing |
| JavaScript (ES6+) | Core language |
| CSS | Styling |
| Fetch API | Data fetching |

---

## 📚 Topics Covered

- **React Components** — Functional components and JSX
- **React Router** — `<Route>`, `<Link>`, `useNavigate`
- **useState** — Managing local state
- **useEffect** — Side effects and lifecycle behaviour
- **Fetch API** — Calling APIs with `async/await`
- **Event Handlers** — `onClick`, `onChange`, `onSubmit`
- **Props** — Passing data between parent and child components
- **Conditional Rendering** — Showing UI based on state

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/dhruvraj927/Ecommerce-Using-React.git

# Go into the project folder
cd ecommerce

# Install dependencies
npm install

# Start the development server
npm start
```
